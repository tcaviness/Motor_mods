# Motor_mods 
Pololu motor driver that work with micropython. 

## Dvr8833 
  To get the DVR88833 ready you have to call
  dvr8833(x,x,x,x) put your pins you are using where the x are and put it in the object you want it to be contained in. 
  From your object you can call foward(), reverses(), turn_left(), and turn_right() with the speed with this functions in 1 to 100.
